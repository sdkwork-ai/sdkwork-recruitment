# Runbooks

Operational runbooks for `sdkwork-recruitment`.

No deployable runtime exists at scaffold time. Add a runbook when a service, database, queue, or scheduled job is introduced:

- `deploy.md`
- `verify.md`
- `observe.md`
- `recover.md`

Follow `../sdkwork-specs/OPERATIONS_SPEC.md` and `../sdkwork-specs/HEALTH_CHECK_SPEC.md`.
