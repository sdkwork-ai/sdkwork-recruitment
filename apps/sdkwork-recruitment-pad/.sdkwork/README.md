# sdkwork-recruitment-pad Workspace Metadata

This `.sdkwork/` directory is source-controlled surface-local development metadata. It is not runtime state or generated SDK output.

- `skills/` — surface-local agent skills.
- `plugins/` — surface-local agent plugins.

Repository-wide skills and plugins live in the repository root `.sdkwork/`. Do not duplicate them here.

Follow `../../../sdkwork-specs/SDKWORK_WORKSPACE_SPEC.md`.
